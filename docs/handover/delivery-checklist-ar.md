## 1. GitHub

- [ ] الفرع المنشور: `main`، وآخر commit منشور: `…………` بتاريخ `…………`.
- [ ] CI أخضر على ذلك الـcommit (رابط التشغيل: …………).

- [ ] التحقق بخطوتين مفعَّل لكل من له صلاحية كتابة.

## 2. Coolify
- [ ] حساب المدير باسم العميل وبتحقق بخطوتين.
- [ ] التطبيقات الثلاثة (web، api، worker) وموردا PostgreSQL وRedis موجودة وتعمل.
- [ ] الـcommit المنشور لكل تطبيق: web `…………` · api `…………` · worker `…………`.
- [ ] فحص الصحة مفعَّل للـAPI والواجهة (أمر `node`، لا `curl`).
- [ ] النشر التلقائي: مطفأ / مفعَّل عمداً (اشطب غير المناسب).

## 3. الدومينات
- [ ] النطاق مسجَّل باسم العميل، وتاريخ التجديد: …………، والتجديد التلقائي مفعَّل.
- [ ] الأسماء الخمسة (الأساسي، `admin`، `main`، `agent`، `pos`) تفتح بـHTTPS.
- [ ] الـAPI بلا نطاق عام.

## 4. Cloudflare
- [ ] الحساب باسم العميل وبتحقق بخطوتين.
- [ ] DNS النطاق عليه؛ وضع الوكيل: مطفأ / مفعَّل (ومعه `TRUST_PROXY` = ……).
- [ ] Bucket النسخ خاص: لا رابط عام ولا نطاق مخصص.
- [ ] قاعدتا القفل موجودتان: `smilesim/daily/` 90 يوماً، `smilesim/monthly/` 365 يوماً.
- [ ] قاعدتا دورة الحياة موجودتان (91 و366 يوماً).
- [ ] رمزان محصوران بالـBucket: كتابة للخادم، قراءة فقط خارجه.

## 7. التخزين والنسخ الاحتياطي
- [ ] السكربتات مركَّبة في `/opt/smilesim-backup` والإعدادات في `/etc/smilesim-backup` (600).
- [ ] أول نسخة يدوية نجحت بتاريخ ………… ومعرّفها …………
- [ ] المؤقّتان مفعَّلان: النسخ الليلي (الوقت: ……) وفحص الحداثة.
- [ ] ثلاث ليالٍ متتالية ناجحة في `backup.log`.
- [ ] النسخة المحلية تبقى 7 أيام؛ مساحة القرص الحرة: …… غيغابايت.

## 8. المفاتيح والملفات الحساسة
- [ ] `SECRETS_KEY` مضبوط على الـAPI وطوله 32 (فُحص دون عرضه).
- [ ] `SECRETS_KEY` نفسه مضبوط على الـWorker (الـWorker لا يقلع في الإنتاج بدونه).
- [ ] نسختان من `SECRETS_KEY` خارج الخادم (المكانان في سجل الأسرار).
- [ ] المفتاح الخاص للنسخ **غير موجود** على الخادم.
- [ ] نسختان من المفتاح الخاص وعبارة مروره خارج الخادم.
- [ ] لا سرّ في Git (فُحص).
- [ ] «سجل الأسرار» مملوء ومسلَّم.
