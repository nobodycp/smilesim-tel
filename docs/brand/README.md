# Smile Sim mark

The SIM with the S, without the wordmark and the smile under it (owner, 2026-11-16).

- `smilesim-mark.svg` — the vector, traced from the owner's 768px picture: the SIM's outline with its gradient
  (`#cc3448` at the top start to `#341e58` at the bottom end) and the S in white on top. Square canvas with 6% of air
  around the mark, transparent background.
- `smilesim-mark-{1024,512,192,64,32}.png` — the same, rendered with a transparent background.

The web app's default tab icon, `apps/web/app/icon.svg`, is this mark. A saved branding icon or logo
(«الإعدادات» → the branding page) still takes its place, as before.

The outline is a trace of a raster picture: its straight edges carry a faint wobble at very large sizes. A redraw
from the designer's original vector, if there is one, would replace it.
