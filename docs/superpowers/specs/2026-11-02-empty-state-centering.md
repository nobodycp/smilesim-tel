# سبك: توسيط الحالة الفاضية (`EmptyState`) — 2026-11-02

## المشكلة

`.empty.empty-state` (شارة الأيقونة الدائرية فوق العنوان، `components/empty-state.tsx`) مُعرَّف بـ`display: grid; justify-items: start; gap: 6px` عشان الأيقونة تترتب فوق العنوان بمسافة واضحة. لكن قاعدة لاحقة بنفس الملف:

```css
.canvas .empty,
.pane .empty,
.sheet .empty { display: block; padding: 14px; }
```

عندها نفس درجة التخصيص (specificity: صنفان) وتجي بعدها بترتيب الملف، فتكسب وتلغي `display: grid` كل مرة يكون فيها `EmptyState` داخل `.pane`/`.sheet`/`.canvas` — وهذا كل استخدام فعلي تقريبًا، لأن كل جداول `DataTable`/`PagedTable` تحطه داخل `.sheet`.

النتيجة: عنصر الأيقونة (مربّع ٢rem بصريًا دائرة) يتحول لعنصر block عادي بلا `justify-items`، فهو والعنوان يترصّان بشكل افتراضي عالحافة الداخلية للسطر (start = يمين بالعربي، يسار بالإنجليزي)، بدل ما يتوسطوا بمساحة الجدول الفاضية. هذا يصير **بكل صفحة** تستخدم `EmptyState` (تقريبًا كل صفحة فيها جدول) — مو خلل خاص بصفحة العمليات، هذا سبب ظهوره "بكل النظام" بنفس الشكل.

## القرار

1. نستثني `.empty-state` من قاعدة `display: block` العامة بإضافة `:not(.empty-state)` على الثلاث selectors، عشان لا تكسر الـgrid الخاص بها.
2. `.empty.empty-state` ياخذ بنفسها `padding: 14px` (نفس القيمة الموثقة بـ`content-ui.mdc`)، زائد توسيط أفقي وعمودي: `justify-items: center; align-content: center; text-align: center; min-height: 100%`. هذا يخلي الأيقونة والعنوان يتوسطوا بمساحة `.sheet`/`.pane` الفاضية (اللي غالبًا طويلة لما الجدول يبقى بلا صفوف) بدل ما يلزقوا بالزاوية.
3. `<p className="empty">` الوحيد المتبقي بدون `empty-state` (استخدام نص مجرد بصفحة تفاصيل باقة المزود، `providers/[code]/[packageCode]/page.tsx:288`) ما يتأثر: يبقى `display: block; padding: 14px` زي ما هو.
4. لا تغيير على الألوان (كل القيم tokens موجودة أصلاً بالوضعين) ولا على بنية `EmptyState` بالـTSX ولا على نص الرسائل.

## خارج النطاق

- تغيير الأيقونة الافتراضية (`tasks`) أو نصوص `t.noMovements`/`t.noMatches`/إلخ.
- أي تعديل على `RowMenu` أو أعمدة الجدول أو `FilterBar`.
- صفحات التفاصيل.

## التحقق

- فحص بصري لصفحة العمليات (حالة فاضية) بالعربي والإنجليزي، فاتح وغامق، على 1440px و390px — الأيقونة والعنوان يتوسطوا، ويتبدّل اتجاههم تلقائيًا مع اللغة (لأنه `text-align: center`/`justify-items: center` محايدين للاتجاه).
- فحص سريع لصفحة ثانية تستخدم `EmptyState` (مثلاً `/packages` بحالة فاضية) للتأكد إن الإصلاح عام وما ينكسر بسياق تاني.
- `npx tsc --noEmit` نظيف (تعديل CSS فقط، بس للتأكد ما انكسر شي بالـTSX المجاور).
