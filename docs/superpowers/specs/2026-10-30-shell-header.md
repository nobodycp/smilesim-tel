# هيدر المكتب

الشريط العلوي فقط. السايد بار يبقى.

- تحية حسب الساعة: صباح الخير قبل الظهر، ومساء الخير بعده، ومعها أول اسم والتاريخ.
- الشريط شفاف بلا خط سفلي، مع ضبابية خفيفة.
- البحث يفتح حقلًا ويجد رقمًا أو حسابًا. الاختصار `/`، والإغلاق Esc.
- الإشعارات جرس بعدد غير المقروء.
- اللغة زر مربّع ينقل إلى اللغة التالية. الوضع زر شمس وقمر.
- الصورة دائرة بالحبر. الضغط يفتح الاسم واسم الدخول والطبقة، ثم الملف الشخصي وتسجيل الخروج.
- رصيد المحفظة يبقى في الشريط.
