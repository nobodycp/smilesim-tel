# Reports like the offer (roadmap N5)

Date: 2026-11-08 · Status: done · Owner: «التقارير، اعملها مثلهم» (`docs/project-plan.md` → 2026-11-08)

One «التقارير» page (`/reports`) for every layer, each report scoped to the viewer's own chain, with tabs:

| Tab | What | Totals | Filters |
|---|---|---|---|
| المبيعات | every sale (activation, renewal, extension, reactivation) under the viewer: when, point of sale, operation, number, company, package, amount paid, my margin | sales, amount, my profit | dates, search |
| الأرباح | the existing profit by package (`/profits`), in the tab | sales, refunds, net | dates, search |
| الطلبات | every line operation: done ones from the ledger, and the open and cancelled tasks | all, done, open, cancelled | dates, search, status |
| الأرصدة | the accounts under the viewer: layer, follows, balance, ceiling, used, available, status, last movement | accounts, balance, used | layer, search, negative only |
| المزودون | branch with the reports grant: per provider over the dates, operations, provider cost, branch profit | operations, cost, profit | dates |

Every tab has «تصدير CSV» with its filters (BOM, shekels). API under `/office/reports/{sales,orders,balances,supply}` and
`…/export` (static routes before `reports/:kind`, which keeps the older branch lists). At most 5,000 rows per report;
`capped` says when there were more. The sidebar's «التقارير» opens the page; the older report links under «غير جاهز»
and «تقارير المزودين» give way to it.
