# خطة بناء الدخول والحساب

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** حساب يدخل باسمه وكلمة سره، ويغيّر بروفايله، ويرى ثلاث جلسات كحد، والفرع يجبر التحقق الثنائي على طبقة.

**Architecture:** `apps/web` يعرض فقط. `apps/api` يملك القواعد. وحدة الدخول واحدة داخل الباك إند. الميزة القادمة تُضاف ملفاً في `apps/api/src/modules/<name>` وسطراً في `featureModules`، وإن احتاجت عملاً خلفياً تضيف معالجاً إلى `backgroundProcessors`. لا تعديل على قرار الدخول ولا على الشاشات من أجل ميزة لا تخصها. شريحة البيع والمهام والرسائل ليست في هذه الخطة.

**Tech Stack:** Node 22، npm workspaces، NestJS 10، Next.js 15، Prisma، PostgreSQL 16، Redis 7، BullMQ، Argon2id، otplib، Jest، Playwright.

## Global Constraints

- الرسائل حرفياً: `بيانات الدخول غير صحيحة`، `الحساب موقوف`، `محاولات كثيرة. أعد المحاولة بعد قليل`، `الرمز غير صحيح`، `كلمة السر الحالية غير صحيحة`.
- ترتيب الفحص: محاولات كثيرة، ثم اسم أو كلمة خاطئة برسالة واحدة، ثم الحساب الموقوف، ثم إجبار تغيير كلمة السر، ثم التحقق الثنائي، ثم جلسة نظام.
- حسابات `branch` و `main` و `agent` و `pos` كلمة سرها `123456`، بلا إجبار تغيير، ومستثناة من التحقق. `branch` وحده `isBranchOwner`.
- الحد 3 جلسات `scope=full`. الرابعة تُنهي الأقدم. جلسة تغيير كلمة السر والتحقق ودخول الفرع اللاحق لا تُحسب.
- الجلسة بلا نشاط 30 يوماً تنتهي. `SESSION_TTL_SECONDS=2592000`.
- عشر محاولات فاشلة خلال 900 ثانية تقفل اسم الدخول حتى تنتهي النافذة.
- الرمز ستة أرقام، الخطوة 30 ثانية.
- النيك نيم من 2 إلى 40 حرفاً بعد القص. كلمة السر الجديدة 8 أحرف على الأقل. التخزين Argon2id.
- الكوكي `sid`: `HttpOnly`. `Secure` و`Domain` من البيئة. جافاسكربت الواجهة لا تقرأه. الطلبات `credentials: 'include'`.
- مسار النظام بجلسة ناقصة يرجع 403. الجلسة المفقودة أو المُخرجة ترجع 401.
- صاحب الفرع فقط يغيّر سياسة الطبقة، والاستثناء، ويلغي ربط تطبيق غيره.
- الواجهة عربية `dir=rtl`. تغيير شكلها لا يعدّل `apps/api`.

## توسعة الميزة القادمة

الميزة الجديدة لا تُكتب في هذه الخطة. موضعها ثابت:

1. مجلد `apps/api/src/modules/<feature>`.
2. إضافة وحدتها في `featureModules`.
3. عملها الخلفي دالة في `backgroundProcessors`.
4. شاشتها مجلداً تحت `apps/web/app` يستدعي مساراً جديداً.
5. جداولها في `schema.prisma` من غير تعديل أعمدة الدخول إلا بمهمة في خطتها.

`AuthContext` الذي تستقبله أي ميزة لاحقة: `{ userId, loginName, layer, sessionId, scope }`. مسار الميزة يطلب `scope=full`.

```ts
export type Layer = 'branch' | 'main_agent' | 'agent' | 'pos';
export type LoginUser = {
  id: string;
  loginName: string;
  disabledAt: Date | null;
  mustChangePassword: boolean;
  layer: Layer;
  twoFactorExempt: boolean;
  twoFactorEnabled: boolean;
  isBranchOwner: boolean;
};

const BAD = { kind: 'error' as const, status: 401 as const, message: 'بيانات الدخول غير صحيحة' };

export function trialUser(layer: Layer): LoginUser {
  return {
    id: layer,
    loginName: layer === 'main_agent' ? 'main' : layer,
    disabledAt: null,
    mustChangePassword: false,
    layer,
    twoFactorExempt: true,
    twoFactorEnabled: false,
    isBranchOwner: layer === 'branch',
  };
}

export function decideLogin(input: {
  user: LoginUser | null;
  passwordMatches: boolean;
  policy: Record<Layer, boolean>;
}) {
  const { user, passwordMatches, policy } = input;
  if (!user || !passwordMatches) return BAD;
  if (user.disabledAt) return { kind: 'error' as const, status: 403 as const, message: 'الحساب موقوف' };
  if (user.mustChangePassword) return { kind: 'session' as const, next: 'password' as const, scope: 'password_change' as const };
  const required = user.twoFactorEnabled || (!user.twoFactorExempt && policy[user.layer]);
  if (required && !user.twoFactorEnabled) {
    return { kind: 'session' as const, next: 'two_factor_enroll' as const, scope: 'two_factor' as const };
  }
  if (required && user.twoFactorEnabled) {
    return { kind: 'session' as const, next: 'two_factor_code' as const, scope: 'two_factor' as const };
  }
  return { kind: 'session' as const, next: 'app' as const, scope: 'full' as const };
}
```

```ts
export const SESSION_LIMIT = 3;
export const SESSION_TTL_SECONDS = 2592000;

type Row = {
  id: string;
  createdAt: Date;
  scope: 'full' | 'password_change' | 'two_factor';
  kind: 'account' | 'impersonation';
  revokedAt?: Date | null;
};

export function idsToRevoke(existing: Row[], creatingNewFullSession: boolean): string[] {
  const countable = existing
    .filter((row) => row.kind === 'account' && row.scope === 'full' && !row.revokedAt)
    .sort((a, b) => a.createdAt.getTime() - b.createdAt.getTime());
  const overflow = countable.length + (creatingNewFullSession ? 1 : 0) - SESSION_LIMIT;
  if (overflow <= 0) return [];
  return countable.slice(0, overflow).map((row) => row.id);
}

export function isListedAccountSession(row: Pick<Row, 'scope' | 'kind' | 'revokedAt'>): boolean {
  return row.kind === 'account' && row.scope === 'full' && !row.revokedAt;
}
```

export interface AuthStore {
  failedCount(loginName: string): Promise<number>;
  recordFailure(loginName: string): Promise<void>;
  clearFailures(loginName: string): Promise<void>;
  findByLogin(loginName: string): Promise<LoginUser & { passwordHash: string } | null>;
  policy(): Promise<Record<Layer, boolean>>;
  listFullSessions(userId: string): Promise<{ id: string; createdAt: Date; scope: 'full'; kind: 'account'; revokedAt: Date | null }[]>;
  saveSession(input: { userId: string; scope: 'full' | 'password_change' | 'two_factor'; userAgent: string; ip: string }): Promise<string>;
  revokeSessions(ids: string[]): Promise<void>;
}

async login(body: { loginName: string; password: string }, meta: { userAgent: string; ip: string }) {
  if (loginBlocked(await this.store.failedCount(body.loginName))) {
    return { status: 429, message: RATE_LIMIT_MESSAGE };
  }
  const user = await this.store.findByLogin(body.loginName);
  const matches = user ? await passwordMatches(user.passwordHash, body.password) : false;
  const decision = decideLogin({ user, passwordMatches: matches, policy: await this.store.policy() });
  if (decision.kind === 'error') {
    if (decision.status === 401) await this.store.recordFailure(body.loginName);
    return decision;
  }
  await this.store.clearFailures(body.loginName);
  if (decision.scope === 'full') {
    const existing = await this.store.listFullSessions(user.id);
    await this.store.revokeSessions(idsToRevoke(existing, true));
  }
  const sessionId = await this.store.saveSession({ userId: user.id, scope: decision.scope, userAgent: meta.userAgent, ip: meta.ip });
  return { status: 200, body: { next: decision.next }, sessionId };
}
